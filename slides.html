The Challenge

Enterprises need AI agents that actually work

Knowledge is siloed

Proprietary docs, wikis, and APIs sit in disconnected systems — LLMs can't reach them out of the box.

Agents are fragile

Generic chatbots hallucinate. Without grounding in real knowledge, answers drift or fabricate.

Integration is manual

Connecting agents to existing tooling (IDEs, pipelines, APIs) requires bespoke glue code per tool.

No lifecycle management

Creating, versioning, deploying, and retiring agents is ad-hoc — no consistent design surface.

Observability is an afterthought

Tracing a question from user to vector store to LLM to response requires custom instrumentation.

Runtime lock-in

Python notebooks and Node.js scripts don't survive production — they need containers, orchestration, ops.

2
The Solution

AgentForge Studio

A complete, integrated AI agent platform where every microservice is a compiled Flogo flow — no runtime dependencies, native Go speed, built-in OTel tracing.

Core Feature

RAG Chat Pipeline

Every answer is grounded in your knowledge base — no hallucination from unconstrained generation.

→

→

→

grounded answer

Response

Document Ingestion

Upload URLs, GitHub repos, or raw text. The ingestion-service chunks, embeds, and stores in Weaviate. One REST call, any source.

Streaming via SSE

The sse-stream-service runs the same RAG pipeline and streams tokens token-by-token to any browser via Server-Sent Events.

Design Portal

AgentForge UI localhost:7025

Agent Gallery

Browse all agents with status tabs (All / Active / Draft / Archived). Search by name or description. One-click deploy or undeploy.

Agent Editor

Configure system prompt, LLM model, knowledge base collection, chunk strategy, and max tokens in a structured form.

AI-Generate Config

Describe what you want in plain English — the agent-builder-service generates a complete JSON config using the LLM of your choice.

One-Click Deploy

Activate agents instantly via the deploy-service. Status transitions: draft → active → archived.

Export for Production

Download a Kubernetes Deployment + Service YAML, or a docker-compose stack — ready to ship.

Feedback Loop

View per-agent feedback ratings and use "Improve" to feed them back to the agent-builder-service for LLM-driven refinement.

MCP Integration

Your AI IDE
gets 9 new tools

Add one line to .mcp.json and Claude Code, Cursor, and VS Code Copilot can call every AgentForge capability natively.

{
  "mcpServers": {
    "agentforge": {
      "type": "http",
      "url": "http://localhost:7333/mcp"
    }
  }
}

 

  • list_agents — browse the registry
  • get_agent — fetch a config
  • create_agent — register a new agent
  • update_agent — update a config
  • deploy_agent — activate / deactivate
  • rag_chat — ask a question
  • ingest_documents — load knowledge
  • submit_feedback — rate a session
  • analyze_flogo — quality analysis

Why Flogo

Native Go · No Runtime · Production Ready

Compiled binaries

Each Flogo app compiles to a single self-contained Go binary via flogobuild. No Node.js, no Python, no JVM. Cold start under 50ms.

Visual flow design

Every service is a Trigger → Activities → Return flow, designed visually and version-controlled as a .flogo JSON file.

Built-in activities

VectorDB, AgentActivity, SSE, REST, File, Log, PostgreSQL — all OOTB. Zero boilerplate for common patterns.

OTel out of the box

Set FLOGO_OTEL_TRACE=true and every service emits spans to an OTLP collector. Trace a question end-to-end across all hops.

Demo Walkthrough

End-to-End Journey

  • 1. Open AgentForge → localhost:7025 · browse existing agents
  • 2. Create agent → pick template or AI-generate config from a prompt
  • 3. Ingest docs → paste a URL or upload text · watch ingestion-service embed & store
  • 4. Deploy agent → one click · status goes draft → active
  • 5. Chat in Chainlit → localhost:7080 · RAG-grounded answers streaming in real time
  • 6. Submit feedback → rate the response from the chat UI
  • 7. Improve agent → Forge reads feedback · LLM refines config
  • 8. Analyze Flogo app → upload a .flogo file · get rule report in <200ms
  • 9. Call via MCP → in Claude Code, call rag_chat with your question
  • 10. Export → download K8s YAML · agent is production-ready

Getting Started

Up in 3 steps

# 1. Start infrastructure
docker compose up weaviate postgres -d

# 2. Pull LLM models
ollama pull nomic-embed-text
ollama pull llama3.2:3b

# 3. Start everything
./start-all.sh

Forge UI and Chainlit start first, then all 9 Flogo services once UIs are ready.
